# Lumiá OHANA - E-commerce Premium

Este é um projeto de e-commerce de alto nível desenvolvido com **Astro.js** e **GSAP**, focado em performance, conversão e autoridade digital.

## 🚀 Tecnologias
- **Astro.js**: Arquitetura de ilhas para performance extrema.
- **GSAP**: Animações fluidas e premium.
- **Vanilla CSS**: Design exclusivo e leve.
- **Mobile-First**: 100% otimizado para dispositivos móveis.

## 📦 Como Iniciar

Como tive um problema técnico para rodar comandos diretamente no terminal deste ambiente, siga os passos abaixo para iniciar o projeto:

1.  Certifique-se de ter o **Node.js** instalado.
2.  No diretório do projeto, execute:
    ```bash
    npm install
    ```
3.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
4.  Abra `http://localhost:4321` no seu navegador.

## ✨ Destaques do Projeto
- **Design System**: Paleta sofisticada (Rosa Suave + Dourado Metálico).
- **Performance**: LCP otimizado e lazy loading nativo.
- **Conversão**: Gatilhos de escassez, prova social e checkout simplificado.
- **SEO**: Estrutura semântica e meta tags dinâmicas.
